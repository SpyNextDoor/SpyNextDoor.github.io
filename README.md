# Jean Marie Ngabonziza — Portfolio

Personal portfolio site for a Data Analyst & Web Developer. Single-page, dark-themed, and fully static.

**Live:** https://spynextdoor.github.io/

## Sections

About · Skills · Projects · Courses · Contact

## Built with

- HTML & CSS (no frameworks, no build step)
- Google Fonts — Inter & IBM Plex Mono
- Responsive layout with a mobile breakpoint at 640px
- Respects `prefers-reduced-motion`

## Run locally

```bash
git clone https://github.com/SpyNextDoor/<repo-name>.git
cd <repo-name>
open index.html
```

Or serve it:

```bash
python3 -m http.server 8000
```

## Structure

```
index.html            # entire site (markup + styles)
resume_updated.pdf    # downloadable résumé
landcover.pdf         # project write-up
```

## Editing

All content lives in `index.html`. Colors and fonts are CSS variables under `:root` — change them there to restyle the whole page.
